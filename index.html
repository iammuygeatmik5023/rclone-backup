rclone 백업

개인용 맥 백업 도구입니다. 오픈소스 프로그램 rclone이 사용자 본인의 Google Drive에 파일을 올리는 데만 씁니다. 다른 사람에게 제공하는 서비스가 아닙니다.

개인정보처리방침

rclone backup

A personal Mac backup tool. It is used only by the open-source program rclone to upload files to the user's own Google Drive. It is not a service offered to anyone else.
